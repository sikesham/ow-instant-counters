# OW Instant Counters

This repo is **public**, not private.

## Text this after Pages is on

https://sikesham.github.io/ow-instant-counters/

## Turn Pages on

1. Open the repo on GitHub.
2. Settings → Pages.
3. Deploy from a branch: `main` / `root` → Save.
4. Wait about one minute.

Until then, after you replace `index.html` with the self-contained phone file, this CDN link also works:

https://cdn.jsdelivr.net/gh/sikesham/ow-instant-counters@main/index.html
